# Sample Applications

These are reference implementations demonstrating iOS 26 features:

## AppleMusicBottomBar
- Demonstrates iOS 26 native tab bar with bottom accessory
- Shows liquid glass effects without backwards compatibility
- Example of modern navigation patterns
- Uses iOS 26 SwiftUI enhancements directly

## AppleMusicMiniPlayer
- Reference implementation of expandable mini player
- Uses iOS 26 navigation transitions
- Demonstrates gesture-driven interactions
- Shows proper state management patterns

Note: These samples require iOS 26.0+ with no backwards compatibility.
